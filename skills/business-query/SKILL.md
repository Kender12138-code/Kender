# 业务数据问答

适用：用户问"上个月卖了多少""哪个商品卖得最好"这类需要查业务库的问题。

## 步骤

1. 先对齐口径：指标定义（销售额还是订单数？）、时间范围、统计维度。缺任何一项就追问，不要自己假设——"上个月"要先确认是哪个月。
2. 调用 `query_database`，把用户的原始问题交给它做自然语言转 SQL，不要自己手写 SQL。
3. 拿到结果后先用一句话给结论，再补一句口径说明：时间范围、统计维度、返回行数（工具最多返回 50 行）。
4. 如果工具提示业务数据库不存在，如实告诉用户，并说明示例库可以用 `python bench_nl2sql.py --rebuild` 生成。
5. 金额和数量要带单位；没有匹配记录就说"没有查到"，不要编数字。

## 注意

- 只读：业务库是以只读方式打开的，写操作会被拒绝，遇到写类需求直接说明不支持。
- 需要"趋势"这类多步问题（例如按月拆开）时，拆成几次查询，而不是拼一条复杂 SQL。
